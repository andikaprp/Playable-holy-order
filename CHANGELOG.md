# Changelog

All notable changes to this mod are documented here.

## [7.0.1] - 2026-07-04

### Added
- Playable vanilla `holy_order_government` with `landless_playable` and Chapter House domicile
- **Become a Grandmaster** interaction (right-click HO Grand Master)
- Title transfer flow: take HO title, strip secular holdings, keep leases
- Templar order systems: commanderies, banking, decisions, events, MaA

### Changed
- Removed Found Holy Order decision and Assume Command interaction
- Overrode game-over rules so Holy Order rulers stay playable
- Succession keeps player on templar heir

### Fixed
- Game Over when switching to Holy Order government
- Domicile init and playable-character triggers for landless HO rulers
