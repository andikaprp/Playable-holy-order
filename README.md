# Playable Templars – Grand Master

CK3 mod: play as a Holy Order Grand Master (landless, leased commanderies, Chapter House domicile).

**Mod version:** 7.0.1  
**Supported CK3:** 1.19.*

## Install

1. Copy this folder to:
   `Documents/Paradox Interactive/Crusader Kings III/mod/playable_templars`
2. Enable **Playable Templars - Grand Master** in the launcher.
3. **Full restart** CK3 after script changes.

## How to play

Right-click an AI Holy Order Grand Master (same faith) → **Become a Grandmaster**.

## GitHub setup (first time)

Install [Git for Windows](https://git-scm.com/download/win), then in this folder:

```powershell
git init
git add .
git commit -m "Initial commit: playable Holy Order Grand Master v7.0.1"
git branch -M main
git remote add origin https://github.com/andikaprp/Playable-holy-order.git
git push -u origin main
```

Create the empty repo on GitHub first (no README), then replace `YOUR_USER` above.
